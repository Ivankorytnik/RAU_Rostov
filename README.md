# RAU_Rostov

Универсальный портал выпускников РВВКИУ РВ / РВИ РВ.

## Идея

Структура портала:

```
РВВКИУ РВ / РВИ РВ
└── Факультет
    └── Год выпуска
        └── Курс / набор
            └── Учебные группы
                └── Выпускники
```

Каждый выпуск получает собственный независимый блок с:

- лентой общения;
- списком однокурсников;
- учебными группами;
- фотоархивом;
- встречами;
- страницей памяти;
- историческими документами;
- собственными администраторами и модераторами.

## Первый реальный блок

4 факультет → выпуск 1991 → 451 курс → группы 4511–4515.

В дальнейшем сюда переносится архив старого сайта 451 курса.

## Дизайн

Военно-историческая цветовая система:

- тёмно-зелёный;
- защитный;
- хаки;
- латунь / золото;
- тёмно-красный как акцент памяти.

На главной используются эмблемы РВСН и РВВКИУ РВ / РВИ РВ.

## Текущий статус

Сейчас реализован front-end MVP:

- каталог выпусков;
- фильтрация по факультету, году, курсу и группе;
- создание нового блока выпуска;
- карточка сообщества;
- разделы Лента / Однокурсники / Фото / Встречи / Память / Документы;
- адаптивный дизайн.

Созданные пользователем блоки временно сохраняются в localStorage браузера.

## Следующий этап

Для production-версии рекомендуется Supabase:

- Auth;
- PostgreSQL;
- Storage;
- Row Level Security;
- роли member / moderator / admin;
- подтверждение принадлежности к выпуску;
- приватные фотоальбомы;
- комментарии и лента;
- мероприятия и RSVP;
- аудит действий модераторов.

## Публикация
